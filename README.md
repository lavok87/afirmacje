# Афірмації: сторінка + віджет на iPhone (безкоштовно)

## 1. Сторінка на екрані «Додому»
1. Відкрийте посилання на сторінку в **Safari**.
2. Торкніться кнопки **«Поділитися»** (квадрат зі стрілкою) → **«На екран „Додому“»** → **«Додати»**.
3. З'явиться іконка «Афірмації» з рожевим серцем. Вона відкривається як окремий додаток і працює без інтернету.

## 2. Віджет через Scriptable
1. Встановіть безкоштовний додаток **Scriptable** з App Store.
2. Відкрийте файл `Afirmacji-widget.js` на iPhone, виділіть увесь текст і скопіюйте.
3. У Scriptable натисніть **«+»**, вставте текст, вгорі назвіть скрипт **Афірмації** і натисніть **Done**.
4. На головному екрані: утримуйте порожнє місце → **Редагувати → Додати віджет → Scriptable** → оберіть розмір → **Додати віджет**.
5. Торкніться доданого віджета (у режимі редагування) → **Script: Афірмації**. За бажанням у полі **Parameter** напишіть `uk` або `pl`.

Віджет показує ту саму афірмацію дня, що й сторінка, і змінює її опівночі.

## 3. Свої афірмації у віджеті
1. На сторінці додайте свої афірмації у вкладці **«Мої»**.
2. Відкрийте вкладку **«Мова»** → **«Копіювати код»**.
3. Відкрийте Scriptable, торкніться скрипта **Афірмації** → **«Імпортувати зі сторінки (з буфера)»**.

У тому ж меню Scriptable можна додати афірмацію прямо у віджет і перемкнути мову.
